# مستند جامع و مرجع فنی کتابخانه GSM (SIM800 / Quectel M08)

یک درایور غیرمسدودکننده (Non-blocking) و کاملاً ماژولار به زبان **C++17** جهت ارتباط پایدار با ماژول های سلولار نظیر **SIM800 / SIM900** و **Quectel M08 / M66**.

این کتابخانه بر اساس اصول مهندسی سیستم های امبدد طراحی شده است:
- **Zero Dynamic Allocation (بدون Heap / malloc / new)**: تمام بافرها در زمان کامپایل رزرو می شوند.
- **بدون وابستگی به STL**: بدون استفاده از `std::vector`, `std::string`, `std::function`.
- **بدون استثناها و تایپ ران تایم (No Exceptions / No RTTI)**: کاملاً سازگار با `-fno-exceptions -fno-rtti`.
- **معماری Non-blocking Tick**: فراخوانی ساده در هر سیکل `tick()` بدون ایجاد تاخیر برای سیستم عامل (FreeRTOS) یا حلقه ی اصلی.
- **پشتیبانی کامل از پیامک فارسی**: پیش فرض کل سیستم روی UCS2 در Text Mode قفل شده است.

## ۲. راه اندازی هوشمند و مکانیزم PWRKEY

در نسخه ی جدید، فرآیند راه اندازی مودم دقیقاً به شرح زیر مدیریت می شود:
1. ابتدا مودم تا ۳ بار دستور `AT` می فرستد.
2. چنانچه پاسخی دریافت نشود (مثلاً ماژول خاموش باشد) و اینترفیس `IPowerControl` به مودم متصل شده باشد، وارد حالت `PowerPulsing` شده و پایه ی **PWRKEY** را به مدت مشخص (`GSM_PWRKEY_PULSE_MS`، پیش فرض ۱۲۰۰ میلی ثانیه) پولس می زند.
3. مجدداً دستورات پروب `AT` ارسال می شوند. اگر باز هم پاسخی دریافت نشود، یک بار دیگر پولس PWRKEY اعمال می شود و در صورت عدم دریافت پاسخ وارد وضعیت `Fault` می گردد.

> **پولس PWRKEY غیرمسدودکننده است:** پورت HAL فقط سطح پین را ست/ریست می کند و همه ی زمان بندی (`assert` → نگه داشتن → `release` → انتظار `GSM_MODEM_BOOT_GUARD_MS` پیش فرض ۲۵۰۰ms → سپس پروب `AT`) داخل `Modem::tick()` انجام می شود.
> در پورت STM32 هیچ `HAL_Delay` وجود ندارد و `power_key()` نباید از داخل وقفه صدا زده شود (دستورهای کنسول هم در حلقه ی اصلی اجرا می شوند، نه در ISR یو آرت).
> PWRKEY **toggle** است. `NORMAL POWER DOWN` حین `PowerPulsing`/`Booting` یعنی ماژول خاموش شد و باید پولس بعدی برای روشن کردن زده شود؛ اگر بعد از `AT`/`RDY` موفق برسد، URC کهنه است و FSM به `Off` نمی رود.

نحوه ی راه اندازی در STM32:
```cpp
static port::Stm32PowerControl pwr(GPIOB, GPIO_PIN_12); // پین PWRKEY
static Modem modem(gsm_uart, clk, kSim800, &pwr);
```

## ۳. صبر برای رجیستر شدن در شبکه و تایم اوت شبکه

مودم پس از پاسخ گویی به `AT`، به صورت پیش فرض کانفیگ نمی شود، بلکه وارد حالت `WaitingRegistration` می شود:
- به صورت متناوب هر ۲ ثانیه دستور `AT+CREG?` را ارسال می کند یا منتظر رخداد URC شبکه ای `+CREG: 1` (شبکه خانگی) یا `+CREG: 5` (رومینگ) می ماند.
- یک تایم اوت مشخص (`GSM_REGISTRATION_TIMEOUT` پیش فرض ۴۵ ثانیه) برای اتصال به شبکه در نظر گرفته شده است. در صورت عدم رجیستر شدن در این مدت، مودم وارد وضعیت `Fault` شده و لاگ خطای شبکه ای ثبت می کند.
- تنها **پس از اطمینان از رجیستر شدن در شبکه**، فرآیند پیکربندی `Configuring` آغاز می گردد.

## ۴. تشخیص زنده اتصال و خارج شدن سیم کارت

سیستم روتر URC و وضعیت سیم کارت به صورت پویا وقایع سیم کارت را پایش می کند:
- کدهای `+CPIN: NOT INSERTED` یا پیام های وضعیت سخت افزاری سیم کارت تشخیص داده می شوند.
- در صورت خارج شدن سیم کارت:
  - مودم وارد وضعیت `SimMissing` می شود.
  - کالبک `on_sim` با وضعیت `SimState::Removed` بلافاصله صدا زده می شود.
  - فرآیندهای پس زمینه متوقف می شوند تا منابع تلف نشوند.
- به محض قرارگیری مجدد سیم کارت (`+CPIN: READY`):
  - کالبک با وضعیت `SimState::Ready` فراخوانی می شود.
  - مودم مجدداً به طور خودکار به مرحله ی `WaitingRegistration` رفته و چرخه را تکمیل می کند.

تعریف کالبک سیم کارت در کد شما:
```cpp
modem.set_on_sim(Modem::SimEventCb([](void*, SimState state) {
    if (state == SimState::Removed) {
        printf("هشدار: سیم کارت خارج شد!\r\n");
    } else if (state == SimState::Ready) {
        printf("سیم کارت متصل شد.\r\n");
    }
}, nullptr));
```

## ۵. استعلام شارژ و کدهای USSD

سرویس اختصاصی `UssdService` با دستور استاندارد `AT+CUSD` اضافه شده است.

### تشخیص خودکار اپراتور:
کتابخانه بر اساس خروجی دستور `AT+COPS?` اپراتور فعال را تفکیک می کند:
- **ایرانسل (Irancell / MTN / 43235)**
- **همراه اول (MCI / TCI / IR-TCI / 43211)**
- **رایتل (RighTel / 43220)**

### استعلام شارژ:
- متد `modem.check_balance()` به صورت کاملاً خودکار بر اساس اپراتور تشخیص داده شده کد USSD مربوطه را ارسال می کند:
  - ایرانسل: `*141*1#`
  - همراه اول: `*140*11#`
  - رایتل: `*140#`
- همچنین می توانید با `modem.ussd("*140#")` هر کد دلخواهی را ارسال کنید.
- پاسخ دریافتی شبکه (حتی در صورت رمزگذاری با UCS2 Hex) به صورت خودکار به متن خوانای فارسی/انگلیسی UTF-8 دیکود می شود.

## ۶. سیستم لاگینگ پیشرفته و رفع مشکل رنگ های ANSI

در نسخه قبلی، زمانی که لاگ ها را به کنسول UART (`writer_sink`) می فرستادید، کدهای رنگی ANSI فرمت بندی نمی شدند و فقط در `stdio_sink` فعال بودند. این مورد کاملاً اصلاح شد:
1. تابع `writer_sink` اکنون مستقیماً کدهای ANSI رنگی را تولید کرده و به سریال می فرستد.
2. کنترل در زمان اجرا (Runtime Toggle):
   ```cpp
   log::Registry::set_color(true);       // فعال/غیرفعال کردن رنگ ها
   log::Registry::set_timestamps(true);  // فعال/غیرفعال کردن نمایش تایم اسکپ [ms]
   log::Registry::set_global_level(log::Level::Debug);
   ```
3. در کنسول تعاملی کلید **`C`** رنگ ها و کلید **`T`** تایم استمپ را در لحظه تغییر می دهد.

## ۷. ماشین حالت اصلی و زیرحالت ها

```
[Off] ──> begin() ──> [Booting] (probe AT x3)
                          │ (fails)
                          └──> [PowerPulsing] (pulse PWRKEY) ──> [Booting]
                                                                     │
[Fault] <── (Reg timeout) <── [WaitingRegistration] <── (AT OK) ─────┘
                                      │
                               (Registered)
                                      ▼
                                [Configuring] (ATE0, CMEE, CMGF, CSCS, CSMP, ...)
                                      │
                                      ▼
                                   [Ready] <═══════════════╗
                                 ╱    │    ╲               ║
                         Job Queued   │   Incoming Call    ║
                                ╱     │     ╲              ║
                               ▼      │      ▼             ║
                          [Working]   │  [Ringing]         ║
                           (SMS,      │      │             ║
                           USSD,      │  (Answer)          ║
                           Call, ...) │      ▼             ║
                               │      │   [InCall]         ║
                               │      │      │             ║
                               └──────┴──────┴─────────────╝
```

## ۸. صف کارها و اولویت ها

- **ظرفیت ثابت (Zero-Alloc)**: تعریف شده با `GSM_QUEUE_DEPTH` (پیش فرض ۶).
- **Urgent Priority**: کارهای اضطراری (مثل `hang_up()` یا `answer()`) از ابتدای صف وارد می شوند.
- **Auto-Retry**: در صورت خطای موقت ماژول یا شبکه، کارها مجدداً تلاش می شوند.
- **کنترل جامع**:
  - `modem.pause_queue()` / `modem.resume_queue()`
  - `modem.stop_all()` (لغو کار جاری با سقط دستور AT و پاک سازی صف)

## ۹. کنسول تعاملی سریال برای تست جامع در STM32

فایل `examples/stm32_main.cpp` را روی بورد پروگرم کنید و ترمینال سریال را با باودریت ۱۱۵۲۰۰ باز کنید:
- کلید **`m`**: نمایش منوی رنگی راهنما
- کلید **`i`**: وضعیت زنده مودم (CSQ, dBm, خطوط آنتن، وضعیت رجیستر شبکه، نام اپراتور، وضعیت سیم کارت)
- کلید **`b`**: استعلام میزان شارژ سیم کارت با کد USSD هوشمند اپراتور
- کلید **`q`**: مشاهده وضعیت صف کارها و کارهای در انتظار
- کلید **`s`**: اجرای استعلام وضعیت کامل (Sweep)
- کلید **`r`**: اسکن پیامک های خوانده نشده
- کلید **`d`**: پاک سازی پیامک های خوانده شده از حافظه
- کلید **`h`**: قطع تماس فوری
- کلید **`T`**: روشن/خاموش کردن برچسب زمانی لاگ ها
- کلید **`C`**: روشن/خاموش کردن رنگ های ANSI لاگ ها
- کلید **`P`**: سوئیچ به حالت Passthrough Bridge (ارتباط مستقیم بایت به بایت با مودم و خروج با `e`)
- دستور **`sms 09037744527 سلام دنیا`**: ارسال پیامک فارسی
- دستور **`dial 09037744527`**: برقراری تماس صوتی
- دستور **`ussd *140#`**: ارسال کد دلخواه USSD
- دستور **`at AT+CSQ`**: اجرای مستقیم فرمان AT بدون تداخل با FSM

## ۱۰. راهنمای گیت، ایجاد مخزن مستقل و Git Submodule

### ۱. ساخت مخزن مستقل در مسیر کتابخانه:
```bash
cd Libraries/DEF/gsm
git init
git add .
git commit -m "feat: complete non-blocking GSM driver with USSD, SIM detection, and PWRKEY support"
```

### ۲. ارسال به گیت هاب:
```bash
git remote add origin https://github.com/<your-username>/gsm-modem.git
git branch -M main
git push -u origin main
```

### ۳. اضافه کردن به عنوان Git Submodule در پروژه اصلی:
در شاخه اصلی پروژه تان:
```bash
# حذف پوشه محلی موقت
rm -rf Libraries/DEF/gsm

# اضافه کردن ساب ماژول در همان مسیر
git submodule add https://github.com/<your-username>/gsm-modem.git Libraries/DEF/gsm
git commit -m "chore: add gsm library as git submodule"
git push
```
