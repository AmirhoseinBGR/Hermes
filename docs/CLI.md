# راهنمای کنسول تعاملی (gsm::cli::Console)

> نسخه ۰.۴ — کنسول `gsm_cli` از اپلیکیشن به **هسته کتابخانه** منتقل شد و یک قابلیت رسمی از کتابخانه است.

## ۱. چرا منتقل شد؟

کنسول تعاملی قبلاً در پوشه `gsm_cli` داخل اپلیکیشن زندگی می‌کرد و فقط برای همان پروژه قابل استفاده بود. چون کارایی خود را ثابت کرده بود، به هسته کتابخانه منتقل شد:

```
قبل:  App/gsm_cli/cli.cpp          (۱۱۰۰+ خط، وابسته به STM32 HAL)
بعد:  gsm/include/gsm/cli/cli.hpp  ← کنسول قابل حمل (کتابخانه)
      gsm/src/cli.cpp
      App/gsm_cli/cli.cpp          ← فقط چسب سخت‌افزاری (~۱۰۰ خط)
      gsm/user_code/cli.cpp        ← همان چسب برای مثال STM32
```

حالا هر پروژه‌ای (STM32، Arduino، تست میزبان) با چند خط، همان کنسول را دارد.

## ۲. راه‌اندازی سریع

```cpp
#include "gsm/cli/cli.hpp"

static gsm::cli::Console console(modem, clock);

// خروجی: هر بایت‌سنکی (سریال، وب، تست)
static void uart_write(void*, const char* data, uint16_t len) { uart.write(data, len); }

void init() {
    console.set_output(gsm::cli::TextSink{&uart_write, nullptr});
    modem.begin();
    console.init();       // ثبت کال‌بک‌ها + رسم منو
}

void loop() {
    modem.tick();
    console.tick();
    while (uart.readable()) console.feed(uart.read_byte());   // ورودی کاربر
}
```

بدون هیپ، بدون STL — مانند بقیه کتابخانه.

## ۳. دستورها و کلیدها

### نمایش وضعیت
| ورودی | عملکرد |
|---|---|
| `m` | رسم مجدد منو |
| `i` | وضعیت زنده (رفرش خودکار هر ۲ ثانیه) |
| `q` | جزئیات صف کارها |
| `w` | پنل واچ‌داگ و سلامت |
| `s` | استعلام وضعیت کامل (Sweep) |
| `r` | اسکن پیامک‌های خوانده‌نشده |
| `d` | پاک‌سازی پیامک‌های خوانده‌شده |
| `b` | استعلام شارژ (USSD هوشمند اپراتور) |

### اقدامات و بازیابی
| ورودی | عملکرد |
|---|---|
| `p` | توقف/ادامه صف |
| `x` | توقف همه و پاک‌سازی صف |
| `h` | قطع فوری تماس (اضطراری) |
| `R` | ریست نرم‌افزاری FSM |
| `K` | ریست سخت‌افزاری با PWRKEY (غیرمسدودکننده؛ `NORMAL POWER DOWN` حین چرخه پولس روشن‌کردن می‌زند و بعد از `AT` کهنه شمرده می‌شود تا دستگاه به `Off` نرود) |
| `P` | پل Passthrough (خروج با `e`) |
| `health` | اجرای بررسی سلامت |
| `wreset` | درخواست ریست نگه‌بانی |

### سیاست‌ها (جدید در v0.4)
| ورودی | عملکرد |
|---|---|
| `smsmax <n>` | تنظیم سقف طول پیامک (کاراکتر) |
| `callto <ms>` | تنظیم تایم‌اوت قطع خودکار تماس |
| `L` / `T` / `C` | سطح لاگ / تایم‌استمپ / رنگ ANSI |

### دستورات متنی
```
sms <num> <text>    ارسال پیامک (فارسی/انگلیسی)
dial <num>          تماس صوتی
ussd <code>         ارسال کد USSD
read <idx>          خواندن پیامک
del <idx>           حذف پیامک
at <cmd>            اجرای مستقیم فرمان AT
```

## ۴. پل وب (Web Bridge)

کنسول می‌تواند هم‌زمان رویدادها و لاگ‌ها را به یک مصرف‌کننده خارجی (پنل وب) آینه کند:

```cpp
console.set_web_output([](const char* line, void* ud) {
    // هر خط، یک پیام آماده برای پنل وب
}, nullptr);

console.exec_web("sms 0912... سلام");   // اجرای دستور از پنل وب
console.status_line(buf, sizeof(buf));  // وضعیت فشرده CSV برای پنل:
// fsm|act|step|ready|sim|net|op|rssi|bars|smsu|smst|paused|qsize|qcap|call|peer
```

در حالت وب (`exec_web`)، رندرهای تمام‌صفحه (منو/وضعیت زنده) سرکوب و فقط متن ساده ارسال می‌شود.

## ۵. Passthrough

با `P` (یا `console.set_passthrough(true)`) تمام بایت‌ها به‌صورت خام بین ترمینال و ماژول جابه‌جا می‌شوند — برای دیباگ مستقیم AT. خروج با `e`.

## ۶. رویدادها

کنسول در `init()` این کال‌بک‌ها را روی مودم نصب می‌کند و رنگی چاپ می‌کند:
- پیامک دریافتی (با پاسخ خودکار به `ping` با `pong`)
- تغییر وضعیت تماس + دلیل پایان تماس
- رویداد سیم‌کارت (خروج/آماده)
- نتیجه هر جاب (با کد خطا)
- گزارش سلامت

## ۷. نکته برای اپلیکیشن‌ها

API چسب اپلیکیشن (`cli::init/tick/on_uart_rx/on_uart_error/set_web_output/exec_web/status_line`) دقیقاً مانند قبل باقی مانده است؛ فقط پیاده‌سازی به کنسول کتابخانه واگذار شده. مراجعه کنید به `docs/fa/files/app-gsm_cli-cli.cpp.md`.
