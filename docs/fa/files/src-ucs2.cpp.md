# gsm/src/ucs2.cpp

## نقش فایل

پیاده‌سازی `gsm::codec`؛ مبدل‌های متنی بین UTF-8 (قالب داخلی کتابخانه) و هگز UCS2/UTF-16 (قالب موردنیاز مودم‌ها وقتی `AT+CSCS="UCS2"` فعال است). این فایل هم برای **ارسال** (متن پیامک و شماره مقصد → هگز UCS2) و هم برای **دریافت** (هگز UCS2 مودم → UTF-8) به کار می‌رود و چند تابع کمکی تشخیص/شمارش هم دارد. همه تبدیل‌ها بدون heap و با مدیریت صریح ظرفیت بافر انجام می‌شوند.

## توابع و منطق کلیدی

### توابع داخلی (anonymous namespace)
- `hex_digit(uint8_t)` / `hex_val(char)` — تبدیل رقم ↔ نویسه هگز (ورودی کوچک/بزرگ هر دو پذیرفته می‌شود).
- `utf8_next(const char* s, uint32_t& cp)` — دیکودر یک نقطه کد UTF-8 (۱ تا ۴ بایت)؛ طول مصرف‌شده را برمی‌گرداند و در دنباله نامعتبر (بایت ادامه بدون سر) صفر برمی‌گرداند.
- `put_unit(char* out, cap, w, unit)` — نوشتن یک واحد ۱۶ بیتی به‌صورت ۴ نویسه هگز؛ کمبود ظرفیت → `false`.

### `uint16_t utf8_to_ucs2_hex(const char* utf8, char* out, uint16_t out_cap)`
هر نقطه کد UTF-8 را به واحد UTF-16 تبدیل و به‌صورت هگز می‌نویسد:
- کاراکترهای BMP (`cp ≤ 0xFFFF`) → یک واحد ۴ رقمی.
- کاراکترهای فراتر از BMP (ایموجی و …) → **جفت سورگیت** (`0xD800 + …` و `0xDC00 + …`)، یعنی دو واحد.
- دنباله UTF-8 خراب یا کمبود ظرفیت → خروجی تا همان‌جا نوشته و `0` برمی‌گردد.

```cpp
if (cp <= 0xFFFF) { put_unit(..., cp); }
else {
    cp -= 0x10000u;
    const uint16_t hi = 0xD800u + (cp >> 10);
    const uint16_t lo = 0xDC00u + (cp & 0x3FFu);
    put_unit(..., hi) && put_unit(..., lo);
}
```

### `uint16_t ascii_to_ucs2_hex(const char* ascii, char* out, uint16_t out_cap)`
نام‌گذاری مجدد همان تابع بالا (برای شماره‌های مبدأ ASCII مثل `+98912…` در `AT+CMGS`).

### `uint16_t ucs2_hex_to_utf8(const char* hex, char* out, uint16_t out_cap)`
مسیر برگشت: گروه‌های ۴ رقم هگز → واحد UTF-16 → بازسازی جفت سورگیت (`D800–DBFF` به‌عنوان high نگه داشته می‌شود و با `DC00–DFFF` ترکیب می‌شود) → کدبندی UTF-8 (۱/۲/۳/۴ بایت). روی ظرفیت کافی یا هگز نامعتبر متوقف می‌شود؛ خروجی همیشه null-terminated است.

### `bool looks_like_ucs2_hex(const char* s)`
تشخیص اینکه یک رشته دریافتی از مودم «احتمالاً هگز UCS2» است: همه نویسه‌ها هگز، طول ≥ ۴ و مضرب ۴. این تابع ستون فقرات «بو کردن» رمزنگاری در `SmsService` و `UssdService` است.

### `uint16_t ucs2_units(const char* utf8)`
تعداد واحدهای UTF-16 موردنیاز برای یک متن UTF-8 (کاراکترهای فراتر از BMP دو واحد حساب می‌شوند)؛ برای گزارش ظرفیت پیامک به کار می‌رود.

### `bool is_ascii_only(const char* utf8)`
بررسی اینکه آیا متن فقط بایت‌های ۷ بیتی دارد (تصمیم `SmsService` برای ماندن روی GSM7 به‌جای UCS2).

## جریان کاری

```text
ارسال پیامک (UCS2):
   "سلام" (UTF-8) ──utf8_to_ucs2_hex──► "0633064406270645" ──► write_raw + Ctrl+Z

دریافت پیامک:
   "+CMGL: …" متن هگز ──looks_like_ucs2_hex──► true ──ucs2_hex_to_utf8──► UTF-8

شماره مقصد (مودم‌های با ucs2_recipient_required):
   "+98912…" ──ascii_to_ucs2_hex──► هگز UCS2 داخل AT+CMGS="…"
```

## نکات فنی

- **جفت سورگیت کامل:** هر دو جهت تبدیل از جفت‌های سورگیت UTF-16 پشتیبانی می‌کنند؛ ایموجی و نشانه‌های فراتر از BMP بدون خرابی منتقل می‌شوند.
- **پشتیبانی کامل UTF-8:** دیکودر `utf8_next` تا ۴ بایت را می‌پذیرد؛ دنباله‌های خراب → بازگشت صفر و شکست تبدیل (بدون رفتار تعریف‌نشده).
- **سیاست شکست:** `utf8_to_ucs2_hex` در صورت کمبود ظرفیت، خروجی را null-terminate و `0` برمی‌گرداند؛ فراخواننده (`SmsService::advance_step`) با `write_escape()` + `fail` واکنش نشان می‌دهد.
- **`looks_like_ucs2_hex` ممکن است مثبت کاذب داشته باشد** (مثلاً متن انگلیسی خالص از اعداد/حروف A–F)؛ برای همین `decode_ussd_text` در `ussd_service.cpp` اول به `dcs` گزارش‌شده اعتماد می‌کند و فقط در نامشخص‌بودن، «بو» می‌کند.
- **بدون heap:** همه بافرها (`out`) توسط فراخواننده با اندازه ثابت (`GSM_SMS_TEXT_BYTES`، `GSM_SMS_NUMBER_BYTES`) تأمین می‌شوند.
- **هگز بزرگ/کوچک:** `hex_val` هر دو را می‌پذیرد؛ `hex_digit` همیشه بزرگ تولید می‌کند (سازگار با انتظار مودم‌ها).

## ارتباط با سایر فایل‌ها

- `gsm/codec/ucs2.hpp` — اعلان توابع.
- `src/sms_service.cpp` — رمزنگاری متن و شماره در `SendHeader`/`WritePayload` و رمزگشایی در `parse_cmgr_header`/`store_body`.
- `src/call_service.cpp` — رمزگشایی شماره UCS2 در پاسخ‌های `+CLIP`/`+CLCC`.
- `src/ussd_service.cpp` — `encode_ussd_text`/`decode_ussd_text` (پیام‌های `+CUSD`).
- `src/at_types.cpp` — کد خطای CMS 3518 (مقصد UCS2 نشده) دقیقاً به همین مبدل مربوط است.
