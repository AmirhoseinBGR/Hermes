# راهنمای سیاست سخت گیرانه طول پیامک (SMS Length Guard)

> نسخه ۰.۴ — محافظت در برابر هنگ ماژول و ارسال پیام خالی در M08R

## ۱. مشکل

ماژول های خانواده M08R در شرایط خاصی (به خصوص متن های بلند یا ارسال در میانه عملیات دیگر) هنگ می کنند و گاهی **پیامک خالی** ارسال می کنند. برای حاشیه امن، کتابخانه یک محدودیت **سخت گیرانه و قابل تنظیم** روی طول متن خروجی دارد.

## ۲. قانون

- طول پیام با **تعداد کاراکترهای UTF-8** (کاراکترهایی که کاربر می بیند، نه بایت ها) سنجیده می شود.
- یک پیامک UCS2 تک بخشی حداکثر **۷۰ کاراکتر** است.
- پیش فرض کتابخانه **۶۰ کاراکتر** است — یعنی **کمتر از یک پیام**، برای حاشیه امن.
- اگر متن بلندتر باشد، پیام **ارسال نمی شود** و فوراً با کد خطای `kErrSmsTooLong = -100` رد می شود.

## ۳. تنظیم طول مجاز

### زمان کامپایل:

```c
// در gsm_config.hpp یا فایل کانفیگ کاربر
#define GSM_SMS_MAX_CHARS 60
```

### زمان اجرا:

```cpp
modem.sms().set_max_chars(45);   // سخت گیرانه تر
uint16_t now = modem.sms().max_chars();
modem.sms().set_max_chars(0);    // 0 = غیرفعال کردن گارد (فقط برای شرایط خاص!)
```

## ۴. رفتار در هنگام رد شدن

### از طریق API مودم (پیشنهادی):

```cpp
JobId id = modem.send_sms("0912...", text, my_callback);
if (id == kInvalidJob) {
    // یا صف پر بود یا متن بلند بود — دلیل در لاگ و کال بک مشخص است
}
```

کال بک بلافاصله با یک جاب `Failed` صدا زده می شود:

```cpp
void my_callback(void*, const Job& job) {
    if (job.result.code == kErrSmsTooLong) {
        // متن بلند بود؛ هیچ فرمان AT ای ارسال نشده است
    }
}
```

### از طریق SmsService (استفاده مستقیم):

```cpp
if (!modem.sms().start_send(number, text)) {
    // یا سرویس مشغول بود یا متن بلند (result = Error/kErrSmsTooLong)
}
```

نکته: این خطا **تلاش مجدد نمی شود** (non-retryable) — چون تکرار همان متن بلند فقط تلف کردن وقت است.

## ۵. شمارش کاراکتر

```cpp
uint16_t n = gsm::SmsService::count_chars("سلام دنیا"); // = 9
```

تابع `count_chars` بایت های ادامه دهنده UTF-8 را نمی شمارد؛ «سلام» ۴ کاراکتر است نه ۱۲ بایت.

## ۶. ارتباط با سایر محافظت ها

| محافظت | فایل | توضیح |
|---|---|---|
| گارد طول | `sms_service.cpp` | رد متن بلند قبل از هر فرمان AT |
| ESC ایمن | `sms_service.cpp` | خروج از حالت prompt با ESC در صورت خطا/لغو |
| گیت تماس | `modem.cpp` | ارسال پیامک در حین تماس اصلاً شروع نمی شود |
| ریست های دوره ای | `watchdog.cpp` | جلوگیری از انباشت خرابی ماژول در درازمدت |
