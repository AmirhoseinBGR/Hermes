کلاس کوچک و متمرکز برای نرمال سازی شماره تلفن به قالب E.164 (مثلاً +989123456789). با توجه به کاربرد ایرانی کتابخانه، کد کشور پیش فرض +98 است؛ ورودی هایی مثل 0912... یا 912... به شکل استاندارد بین المللی درمی آیند. این کلاس مبنای شماره های SmsService و CallService است.

ساختارهای کلیدی

class PhoneNumber

class PhoneNumber
{
  public:
    PhoneNumber() = default;
    explicit PhoneNumber(const char* raw, const char* country_code = "+98")
    { assign(raw, country_code); }

    bool        assign(const char* raw, const char* country_code = "+98");
    const char* e164() const { return value_.c_str(); }
    bool        valid() const { return value_.size() >= 8; }
    void        clear() { value_.clear(); }

  private:
    StaticString<GSM_SMS_NUMBER_BYTES> value_;   // 24 bytes by default
};
  • assign(raw, country_code): نرمال سازی ورودی خام (با/بدون صفر اولیه، با/بدون +) به E.164؛ مقدار بازگشتی موفقیت عملیات را نشان می دهد.
  • e164(): رشتهٔ نهایی با پیشوند + (برای AT+CMGS، ATD و …).
  • valid(): حداقل ۸ رقم — فیلتر سادهٔ شماره های آشکارا ناقص (شمارهٔ ایرانی کامل ۱۲ رقم با کد کشور است).
  • clear(): بازنشانی.

نکات فنی

  • بدون heap / بدون STL: ذخیره در StaticString<GSM_SMS_NUMBER_BYTES> (پیش فرض ۲۴ بایت؛ برای E.164 کافی است).
  • سازنده explicit است تا تبدیل ضمنی رشته به شماره رخ ندهد.
  • نرمال سازی در assign پیاده سازی شده (در .cpp)؛ هدر فقط قرارداد را نشان می دهد.
  • valid() یک اعتبارسنجی حداقلی است (طول)؛ اعتبارسنجی الگوی کشور/اپراتور بر عهدهٔ کاربر است.
  • شماره های USSD یا کدهای کوتاه ممکن است از valid() رد نشوند — از این کلاس برای شماره های مکالمه/پیامک استفاده کنید.
  • value_ همیشه null-terminated است (تضمین StaticString).
