gsm/CMakeLists.txt

نقش فایل

پیکربندی ساخت (build) کتابخانه ی ایستای gsm_modem با CMake. این فایل فهرست فایل های منبع هسته را جمع می کند، کتابخانه ی ایستا (STATIC) می سازد، مسیرهای include را تنظیم می کند، گزینه های کامپایل (بدون استثنا/RTTI، هشدارها) را اعمال می کند و دو گزینه ی اختیاری برای پُرت STM32 و تست میزبان فراهم می کند.

ساختارها/توابع کلیدی

  • cmake_minimum_required(VERSION 3.16) و project(gsm_modem CXX) — حداقل نسخه ی CMake و نام پروژه (زبان C++).
  • set(CMAKE_CXX_STANDARD 17) + set(CMAKE_CXX_STANDARD_REQUIRED ON) — استاندارد C++17 اجباری.
  • add_library(gsm_modem STATIC ...) — ساخت کتابخانه ی ایستا از فایل های src/:

log.cpp, at_types.cpp, line_reader.cpp, urc_router.cpp, at_engine.cpp, ucs2.cpp, phone_number.cpp, sms_service.cpp, call_service.cpp, status_service.cpp, ussd_service.cpp, job_queue.cpp, watchdog.cpp, modem.cpp, cli.cpp.

  • target_include_directories(gsm_modem PUBLIC include) — پوشه ی include/ به عنوان مسیر include عمومی.
  • target_compile_options(gsm_modem PRIVATE ...) — هشدارها (-Wall -Wextra -Wshadow) و بهینه سازی حجم (-ffunction-sections -fdata-sections) به همراه -fno-exceptions -fno-rtti.
  • option(GSM_PORT_STM32 "Build the STM32 HAL port" OFF) — اگر روشن باشد ports/stm32 به include اضافه می شود.
  • option(GSM_BUILD_TESTS "Build the host smoke test" OFF) — اگر روشن باشد:
  • add_executable(host_smoke tests/host_smoke.cpp)
  • target_link_libraries(host_smoke PRIVATE gsm_modem)
  • target_include_directories(host_smoke PRIVATE ports/host)
  • enable_testing() و add_test(NAME host_smoke COMMAND host_smoke).

جریان کاری

  1. CMake پروژه را با C++17 تعریف می کند.
  2. کتابخانه ی ایستای gsm_modem از پانزده فایل منبع هسته ساخته می شود؛ include/ مسیر include عمومی است.
  3. گزینه های کامپایل سخت گیرانه اعمال می شوند (بدون استثنا/RTTI، مناسب محیط های embedded).
  4. در صورت نیاز، گزینه ی GSM_PORT_STM32 مسیر پُرت STM32 را اضافه می کند.
  5. در صورت نیاز، گزینه ی GSM_BUILD_TESTS اجرایی host_smoke را می سازد، به کتابخانه پیوند می دهد، پُرت میزبان را اضافه می کند و تست را با CTest ثبت می کند.

نکات فنی

  • کتابخانه STATIC است؛ برای مصرف در پروژه های embedded مناسب است.
  • -fno-exceptions -fno-rtti با سیاست «بدون STL پویا/استثنا» سازگار است (همان طور که در library.json هم آمده).
  • -ffunction-sections -fdata-sections به linker کمک می کند کد استفاده نشده را حذف کند (کاهش حجم فریمور).
  • پرچم های کامپایل فقط PRIVATE هستند؛ مصرف کنندگان کتابخانه این پرچم ها را به ارث نمی برند.
  • هر دو گزینه (GSM_PORT_STM32, GSM_BUILD_TESTS) پیش فرض OFF هستند تا ساخت پایه سبک بماند.
  • cli.cpp (کنسول تعاملی v0.4) بخشی از هسته ی کتابخانه است و در add_library فهرست شده است.
  • فهرست منبع دقیقاً با ساختار src/ هم خوان است؛ هر سرویس (SMS، تماس، وضعیت، USSD، صف، واچ داگ) فایل مخصوص به خود را دارد.

ارتباط با سایر فایل ها

  • gsm/src/*.cpp — فایل های منبعی که در کتابخانه گنجانده شده اند.
  • gsm/include/ — سرصفحه های عمومی (مسیر include).
  • gsm/ports/stm32/ — با GSM_PORT_STM32 اضافه می شود.
  • gsm/ports/host/ — برای تست میزبان اضافه می شود.
  • gsm/tests/host_smoke.cpp — هدف تست میزبان.
  • gsm/library.json — متادیتای PlatformIO؛ با این CMake هم راستا است (C++17، بدون استثنا/RTTI).
  • App/CMakeLists.txt — لایه ی اپلیکیشن که gsm_modem را به عنوان وابستگی لینک می کند.
