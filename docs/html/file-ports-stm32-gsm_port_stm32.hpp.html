gsm/ports/stm32/gsm_port_stm32.hpp

نقش فایل

این فایل «پُرت STM32» برای کتابخانه‌ی GSM است و رابط‌های انتزاعی سخت‌افزاری (HAL) را روی میکروکنترلرهای STM32 با کتابخانه‌ی HAL شرکت ST پیاده‌سازی می‌کند. سه بخش اصلی دارد: UART مبتنی بر DMA، زمان‌سنج مبتنی بر HAL_GetTick، و کنترل پین‌های تغذیه/ریست مودم (PWRKEY / RESET). این فایل به main.h (تولیدشده توسط CubeMX) وابسته است تا به هندل‌های UART و GPIO دسترسی داشته باشد.

ساختارها/توابع کلیدی

  • template <uint16_t DmaSize = 256, uint16_t RingSize = GSM_RX_RING_SIZE> class Stm32Uart final : public hal::IUart

UART دریافتی مبتنی بر DMA با حلقه‌ی بافر (RingBuffer<RingSize>) برای تخلیه‌ی داده‌ها.

  • explicit Stm32Uart(UART_HandleTypeDef* huart, uint32_t tx_timeout_ms = 100) — سازنده با هندل UART و مهلت ارسال.
  • void begin() — دریافت DMA را شروع می‌کند (start_rx).
  • UART_HandleTypeDef* handle() const — دسترسی به هندل UART.
  • uint16_t write(const uint8_t* data, uint16_t len) — با HAL_UART_Transmit (Blocking با مهلت) ارسال می‌کند؛ در موفقیت len و در خطا 0.
  • uint16_t read(uint8_t* out, uint16_t max) — تا max بایت از حلقه‌ی RX برمی‌دارد.
  • uint16_t available() — تعداد بایت‌های آماده در حلقه.
  • void drain_rx() — حلقه را خالی می‌کند.
  • void on_rx_event(uint16_t size) — کال‌بک رویداد RX (از HAL_UARTEx_RxEventCallback)؛ داده‌ی جدید DMA را از last_pos_ تا size وارد حلقه می‌کند و حالت wrap-around بافر DMA را مدیریت می‌کند.
  • void on_error() — فلگ‌های خطای UART (ORE/NE/FE) را پاک می‌کند و دریافت را دوباره شروع می‌کند.
  • void set_circular(bool on) — حالت دریافت پیوسته‌ی حلقه‌ای DMA را روشن/خاموش می‌کند.
  • class Stm32Clock final : public hal::IClock
  • uint32_t millis() — HAL_GetTick() را برمی‌گرداند (میلی‌ثانیه‌ی سراسری HAL).
  • class Stm32PowerControl final : public hal::IPowerControl

کنترل پین‌های تغذیه و ریست مودم با پشتیبانی از سطح فعال-پایین.

  • سازنده: Stm32PowerControl(GPIO_TypeDef pwr_port, uint16_t pwr_pin, GPIO_TypeDef rst_port = nullptr, uint16_t rst_pin = 0, bool active_low = true)
  • void power_key(bool asserted) — فقط سطح پین PWRKEY را ست/ریست می‌کند (بدون هیچ تأخیری). زمان‌بندی پولس (assert → نگه داشتن → release → boot guard) در Modem::tick() انجام می‌شود.
  • void reset(bool asserted) — فقط پین RESET را همان لحظه کنترل می‌کند (بدون تأخیر).
  • ⚠️ عمداً هیچ HAL_Delay در این کلاس نیست: اگر این توابع از داخل وقفه صدا زده شوند (مثل دستور کنسول که از ISR یو‌آرت می‌آمد)، HAL_Delay روی تیک SysTick قفل می‌شود و کل دستگاه هنگ می‌کند. power_key() را هرگز از ISR صدا نزنید.

جریان کاری

  1. شروع دریافت: begin() → start_rx() → HAL_UARTEx_ReceiveToIdle_DMA (با غیرفعال کردن وقفه‌ی نیمه‌بافر DMA).
  2. ورود داده: وقفه‌ی DMA → HAL_UARTEx_RxEventCallback → on_rx_event(size) → انتقال بایت‌های جدید از بافر DMA به حلقه‌ی RX.
  3. مدیریت wrap: اگر size از last_pos_ کوچک‌تر باشد (نشانه‌ی چرخش بافر DMA)، داده از last_pos_ تا انتها و سپس از ابتدای بافر DMA خوانده می‌شود.
  4. غیر حلقه‌ای: اگر circular_ خاموش باشد، پس از هر رویداد دریافت دوباره start_rx() صدا زده می‌شود.
  5. ارسال: write از HAL_UART_Transmit Blocking استفاده می‌کند.
  6. تغذیه: Stm32PowerControl پین‌های PWRKEY/RESET را برای روشن کردن یا ریست سخت‌افزاری مودم مدیریت می‌کند.

نکات فنی

  • last_pos_ از نوع volatile uint16_t است چون در زمینه‌ی وقفه تغییر می‌کند.
  • بافر DMA آرایه‌ی uint8_t dma_[DmaSize] با اندازه‌ی پیش‌فرض 256 است.
  • write در صورت ورودی نال/طول صفر، 0 برمی‌گرداند؛ در خطا (غیر HAL_OK) نیز 0 برمی‌گرداند.
  • تفکیک منطق فعال (asserted ^ active_low_) به پین‌های فعال-پایین یا فعال-بالا اجازه می‌دهد با یک سازنده سازگار شوند.
  • on_error فلگ‌های Overrun/Noise/Framing را پاک می‌کند تا UART پس از خطا به حالت عادی برگردد.
  • ماکروی GSM_RX_RING_SIZE باید در main.h یا پیکربندی پروژه تعریف شود.
  • برخلاف پُرت میزبان، اینجا از هیچ STL پویایی استفاده نشده و با -fno-exceptions -fno-rtti سازگار است.
