gsm/include/gsm/core/line_reader.hpp

نقش فایل

تبدیل جریان بایت های دریافتی از UART به واحدهای معنادار پروتکل AT: یک خط کامل (با \r یا \n جدا شده) یا نشان prompt (کاراکتر > که مودم برای دریافت payload پیامک/USSD می فرستد). این کلاس بافر جمع آوری خطوط AtEngine است.

ساختارهای کلیدی

enum class Token : uint8_t

enum class Token : uint8_t
{
    None,      // byte consumed, nothing complete yet
    Line,      // a full line is ready in line()
    Prompt,    // '>' prompt seen (payload mode)
    Overflow   // line exceeded GSM_LINE_MAX; buffer was reset
};

class LineReader

class LineReader
{
  public:
    Token       feed(uint8_t byte);               // consume one byte
    const char* line() const { return buf_.c_str(); }
    uint16_t    length() const { return buf_.size(); }
    void        reset() { buf_.clear(); }

  private:
    StaticString<GSM_LINE_MAX> buf_;
};
  • feed: به ازای هر بایت یک Token برمی گرداند؛ با دریافت terminator خط، محتوای line() معتبر است.
  • line() / length(): محتوای خط جاری/تکمیل شده (رشتهٔ null-terminated).
  • reset: پاک سازی بافر (پس از مصرف خط یا در شروع تراکنش جدید).
  • Overflow: خط از GSM_LINE_MAX (پیش فرض ۵۱۲) بلندتر شده؛ بافر ریست می شود تا خط خراب به تراکنش نشت نکند.

جریان کاری

uart.read() bytes
      |
      v
LineReader.feed(byte) --------------+
      |                             |
      +-> Token::Line   -> UrcRouter.dispatch(line) or observer->on_line(line)
      +-> Token::Prompt -> observer->on_prompt()      (expect_prompt)
      +-> Token::Overflow -> drop the broken line
      +-> Token::None   -> keep feeding

مثال مصرف (در AtEngine::tick):

// Pseudocode inside AtEngine::tick()
switch (reader_.feed(b)) {
    case Token::Line:   handle_line(reader_.line(), reader_.length()); break;
    case Token::Prompt: if (expect_prompt_) observer_->on_prompt();    break;
    case Token::Overflow: /* drop corrupt line */                      break;
    case Token::None:   break;
}

نکات فنی

  • بدون تخصیص حافظه: بافر از نوع StaticString<GSM_LINE_MAX> و روی خود object قرار دارد؛ اندازه با ماکروی GSM_LINE_MAX از gsm_config.hpp کنترل می شود.
  • بدون STL: فقط <cstdint> و StaticString.
  • overflow آشکارسازی می شود (Token::Overflow)؛ خطوط خراب بی صدا حذف می شوند نه اینکه نصفه تحویل شوند.
  • تفکیک URC از پاسخ فرمان بر عهدهٔ این کلاس نیست؛ LineReader فقط قاب بندی خط را انجام می دهد و AtEngine تصمیم می گیرد خط به UrcRouter برود یا به observer.
  • > بدون terminator به عنوان prompt شناخته می شود (برای حالت +CMGS / +CUSD).
