gsm/examples/stm32_main.cpp

نقش فایل

نقطه‌ی ورود (entry point) نمونه‌ی اپلیکیشن STM32. این فایل عمداً حداقلی است: منطق اپ را کوتاه نگه می‌دارد و آزمون تعاملی را به ماژول cli (چسب سخت‌افزاری کنسول کتابخانه) واگذار می‌کند. همچنین کال‌بک‌های رویداد DMA و خطای UART ساخته‌شده توسط CubeMX را به ماژول cli پل می‌زند.

ساختارها/توابع کلیدی

همه به‌صورت extern "C" تعریف شده‌اند تا با چارچوب فراخوانی C سازگار باشند:

  • int AppInit()
  • cli::init() را صدا می‌زند (راه‌اندازی UARTها، مودم، کنسول) و 0 برمی‌گرداند.
  • int AppRun()
  • cli::tick() را صدا می‌زند (یک تیک از مودم + کنسول) و 0 برمی‌گرداند. این تابع در حلقه‌ی اصلی فراخوانی می‌شود.
  • void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef* huart, uint16_t size)
  • کال‌بک رویداد دریافت DMA (از HAL) → cli::on_uart_rx(huart, size).
  • void HAL_UART_ErrorCallback(UART_HandleTypeDef* huart)
  • کال‌بک خطای UART (از HAL) → cli::on_uart_error(huart).

جریان کاری

  1. سیستم/بوت‌لودر پروژه، AppInit() را یک بار صدا می‌زند → cli::init() سخت‌افزار و مودم را آماده می‌کند.
  2. در حلقه‌ی اصلی، AppRun() مرتباً صدا زده می‌شود → cli::tick() مودم و کنسول را جلو می‌برد.
  3. هنگام رسیدن داده به UART (مودم یا دیباگ)، HAL وقفه را مدیریت کرده و HAL_UARTEx_RxEventCallback را صدا می‌زند → cli::on_uart_rx داده را به پُرت/کنسول هدایت می‌کند.
  4. در صورت خطای UART، HAL_UART_ErrorCallback → cli::on_uart_error دریافت را بازیابی می‌کند.

نکات فنی

  • این فایل هیچ منطق تجاری/کنسول ندارد؛ همه‌چیز به ماژول cli و کتابخانه gsm_modem تفویض شده است.
  • توابع extern "C" برای این است که CubeMX/HAL بتواند مستقیماً آن‌ها را به‌عنوان کال‌بک صدا بزند (بدون name mangling).
  • AppInit/AppRun قرارداد نام‌گذاری چارچوب اپ (app.hpp) هستند؛ مقدار بازگشتی 0 به معنای موفقیت است.
  • HAL_UARTEx_RxEventCallback مربوط به دریافت «تا بی‌کار» (Receive-To-Idle) با DMA است؛ همان مکانیزمی که Stm32Uart::on_rx_event انتظار دارد.
  • تفکیک UART مودم (UART7) در برابر UART دیباگ (USART1) داخل cli.cpp انجام می‌شود، نه اینجا.

ارتباط با سایر فایل‌ها

  • gsm/user_code/cli.hpp / gsm/user_code/cli.cpp — ماژول cli که این فایل آن را صدا می‌زند.
  • app.hpp — چارچوب اپلیکیشن که قرارداد AppInit/AppRun را تعریف می‌کند.
  • usart.h (CubeMX) — تعریف هندل‌های UART و کال‌بک‌های HAL.
  • gsm/ports/stm32/gsm_port_stm32.hpp — پُرت UART/Clock/Power که به‌صورت غیرمستقیم از طریق cli.cpp استفاده می‌شود.
  • App/gsm_cli/cli.cpp — نسخه‌ی اپلیکیشن کامل‌تر همین الگو (با پل وب).
