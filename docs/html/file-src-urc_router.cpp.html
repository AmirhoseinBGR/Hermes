gsm/src/urc_router.cpp

نقش فایل

پیاده سازی gsm::UrcRouter؛ مسیریاب پیام های ناخواسته (URC) مودم. هر خط دریافتی از UART را دسته بندی می کند (Urc) و در صورت شناسایی، یک UrcEvent شامل نوع، متن خام و آرگومان عددی به handler مرکزی (Modem::handle_urc) تحویل می دهد. خطوط URC هرگز به observer فرمان جاری نمی رسند؛ این تفکیک، ستون فقرات تمایز «پاسخ فرمان» از «رویداد ناخواسته» در کل کتابخانه است.

توابع و منطق کلیدی

bool UrcRouter::dispatch(const char* line, uint16_t len)

خط را classify می کند؛ اگر Unknown باشد false (یعنی خط، پاسخ عادی فرمان است و باید به observer برسد). در غیر این صورت UrcEvent{kind, line, arg} ساخته، handler را صدا می زند و true برمی گرداند (خط «مصرف» شد).

const Urc kind = classify(line, arg);
if (kind == Urc::Unknown) return false;
UrcEvent ev{kind, line, arg};
if (handler_) handler_(ev);
return true;

جریان کاری

AtEngine::tick ──► خط کامل ──► classify_final؟ (OK/ERROR/…) ──► نتیجه فرمان
                        │
                        └─► urc_.dispatch(line)
                                ├─ Unknown ──► false ──► observer_->on_line()  (پاسخ فرمان)

نکات فنی

  • ترتیب بررسی مهم است: classify اول «دقیق ترین» الگوها را می سنجد (مثلاً +CPIN: READY قبل از +CPIN: عمومی) تا دسته بندی های کلی، موارد خاص را نبلعند.
  • NO CARRIER دو هویتی: در AtEngine::classify_final نتیجه نهایی فرمان (مثلاً ATD) و در اینجا URC پایان تماس است؛ اولویت با classify_final است (در tick اول نتیجه نهایی بررسی می شود)، پس وقتی observer فعالی در انتظار نتیجه است، NO CARRIER به on_final(NoCarrier) می رود نه URC.
  • +CPINهای مبهم: هر حالت +CPIN: غیر از NOT READY/NOT INSERTED به عنوان SimReady گزارش می شود (حتی SIM PIN)؛ StatusService ریزبینانه تر تفسیر می کند.
  • RDY/DY: برخی مودم ها با banner کوتاه DY (بخشی از RDY با تأخیر بافر) اعلام آمادگی می کنند؛ الگوی DY برای همین حالت عجیب اضافه شده است.
  • بدون heap: UrcEvent فقط اشاره گر به line (بافر LineReader) و یک int32_t است؛ handler باید در همان لحظه مصرف کند یا کپی بگیرد.
  • dispatch مالکیت handler را ندارد: handler با set_handler(UrcRouter::Handler(...)) (Delegate ذخیره ای) نصب می شود؛ Modem خودش را با trampoline وصل می کند.
