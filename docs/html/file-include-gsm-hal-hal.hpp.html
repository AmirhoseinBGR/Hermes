gsm/include/gsm/hal/hal.hpp

نقش فایل

این فایل لایهٔ انتزاع سخت افزار (HAL) کتابخانه را تعریف می کند: رابط های خالص برای UART، زمان سنج و کنترل تغذیهٔ ماژول GSM. هدف، جداسازی کامل کد کتابخانه از پلتفرم مقصد است؛ کافی است کاربر پیاده سازی های متناسب با برد خود (STM32، Arduino، شبیه ساز تست و …) را بدهد تا همه جای کتابخانه بدون تغییر کار کند.

ساختارهای کلیدی

class hal::IUart

class IUart
{
  public:
    virtual ~IUart()                                          = default;
    virtual uint16_t write(const uint8_t* data, uint16_t len) = 0;
    virtual uint16_t read(uint8_t* out, uint16_t max)         = 0;
    virtual uint16_t available()                              = 0;
    virtual void     drain_rx()                               = 0;
    virtual bool     set_baud(uint32_t) { return false; }
};
  • write / read: انتقال بایت ها؛ تعداد واقعی خوانده/نوشته شده را برمی گردانند (غیرمسدودکننده).
  • available: تعداد بایت آماده در بافر دریافت.
  • drain_rx: خالی کردن بافر دریافت؛ پیش از شروع هر فرمان AT فراخوانی می شود تا باقیماندهٔ دادهٔ قبلی مخل نشود.
  • set_baud: اختیاری؛ پیش فرض false (پشتیبانی نشده).

class hal::IClock

class IClock
{
  public:
    virtual ~IClock()         = default;
    virtual uint32_t millis() = 0;
};

منبع زمان مونوتونیک به میلی ثانیه با سرریز uint32 (حدود ۴۹ روز). همهٔ تایمرهای کتابخانه بر همین مبنا کار می کنند.

class hal::IPowerControl

class IPowerControl
{
  public:
    virtual ~IPowerControl() = default;
    virtual void power_key(bool asserted) { (void)asserted; }
    virtual void reset(bool asserted) { (void)asserted; }
    virtual bool status() { return true; }
};
  • power_key: پالس پین PWRKEY برای روشن/خاموش کردن ماژول.
  • reset: پین ریست سخت افزاری.
  • status: وضعیت روشن بودن ماژول (پیش فرض همیشه true).

همهٔ متدها دارای پیش فرض بی اثرند؛ در Modem این اینترفیس اختیاری است (nullptr یعنی بدون کنترل تغذیه).

تابع کمکی elapsed

inline bool elapsed(uint32_t now, uint32_t since, uint32_t span)
{ return static_cast<uint32_t>(now - since) >= span; }

محاسبهٔ سپری شدن زمان به صورت مقاوم در برابر سرریز uint32: تفریق ماژولار now - since حتی بعد از پیچیدن ساعت هم درست کار می کند. الگوی استاندارد همهٔ تایمرهای کتابخانه.

جریان کاری

   Application / Board support
   +--------------------------------------+
   | MyUart : IUart   MyClock : IClock    |
   | MyPower : IPowerControl (optional)   |
   +------------------+-------------------+
                      | references
                      v
   Modem(uart, clock, traits, power*)  -->  AtEngine(uart, clock, urc)
                      |
                      +--> hal::elapsed() used by all timers

نمونهٔ حداقلی استفاده:

// Board provides implementations; the library only sees the interfaces.
gsm::hal::IUart& uart  = my_uart;
gsm::hal::IClock& clk  = my_clock;
gsm::Modem modem(uart, clk, gsm::kSim800, &my_power);

نکات فنی

  • بدون تخصیص حافظه و بدون STL: تنها <cstdint>؛ همه چیز reference/pointer و virtual dispatch.
  • متدها غیرمسدودکننده طراحی شده اند — read نباید منتظر داده بماند؛ حلقهٔ اصلی با Modem::tick() داده را می کشد.
  • millis() باید مونوتونیک باشد؛ از elapsed() برای مقایسه ها استفاده کنید نه مقایسهٔ مستقیم now > since (مقاومت در برابر سرریز).
  • drain_rx() حیاتی است: باقیماندهٔ پاسخ فرمان قبلی در بافر، رفتار AtEngine را خراب می کند.
  • اگر IPowerControl داده نشود، Modem::has_power_control() برمی گردد false و قابلیت های pulse_pwrkey / power_cycle عملاً غیرفعال اند.

ارتباط با سایر فایل ها

  • core/at_engine.hpp — AtEngine مستقیماً IUart& و IClock& می گیرد
  • modem/modem.hpp — سازندهٔ Modem این اینترفیس ها را دریافت می کند (IPowerControl* اختیاری)
  • tools/serial_bridge.hpp و cli/cli.hpp — از IUart به عنوان کنسول/پل سریال استفاده می کنند
  • core/line_reader.hpp و util/ring_buffer.hpp — لایه های بافر بالای همین HAL
