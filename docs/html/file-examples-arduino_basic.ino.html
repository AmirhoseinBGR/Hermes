gsm/examples/arduino_basic.ino

نقش فایل

نمونه‌ی مینیمال آردوینو برای نشان دادن اینکه «همان API، فقط دو خط راه‌اندازی متفاوت». این اسکچ ثابت می‌کند کل کتابخانه‌ی GSM (بدون بلوکه شدن) با یک Stream سریال و یک زمان‌سنج آردوینو کار می‌کند: مودم را راه می‌اندازد، پیامک دریافتی را چاپ می‌کند و پس از آماده شدن، یک پیامک فارسی ارسال می‌کند.

ساختارها/توابع کلیدی

  • port::ArduinoUart modem_uart(Serial1) — پُرت UART آردوینو روی Serial1.
  • port::ArduinoClock clk — زمان‌سنج آردوینو.
  • Modem modem(modem_uart, clk, kSim800) — نمونه‌ی مودم SIM800 (بدون کنترل تغذیه).

توابع:

  • void onSms(void*, const SmsMessage& m)

کال‌بک دریافت پیامک؛ شماره (m.number) و متن (m.text) را روی Serial چاپ می‌کند.

  • void setup()
  • Serial.begin(115200) و Serial1.begin(115200).
  • log::Registry::set_color(false) — غیرفعال کردن رنگ ANSI در لاگ (مناسب مانیتور سریال ساده).
  • modem.set_on_sms(SmsService::Received(&onSms, nullptr)) — ثبت کال‌بک پیامک دریافتی.
  • modem.begin() — شروع ماشین حالت مودم.
  • void loop()
  • modem.tick() — پیشرفت غیرمسدودکننده‌ی مودم در هر چرخه.
  • با static bool sent فقط یک بار پس از modem.ready()، پیامک "سلام از آردوینو" به شماره‌ی "09037744527" ارسال می‌شود.

جریان کاری

  1. راه‌اندازی (setup): سریال‌ها با نرخ ۱۱۵۲۰۰ باز می‌شوند، رنگ لاگ خاموش می‌شود، کال‌بک پیامک ثبت می‌شود و modem.begin() ماشین حالت را شروع می‌کند.
  2. حلقه (loop): در هر چرخه modem.tick() صدا زده می‌شود (غیرمسدودکننده).
  3. ارسال یک‌بار: به محض modem.ready() (ثبت شبکه کامل)، یک پیامک فارسی ارسال و پرچم sent ست می‌شود تا دوباره ارسال نشود.
  4. دریافت: هر پیامک ورودی از طریق onSms روی Serial چاپ می‌شود.

نکات فنی

  • پیام متن فارسی ("سلام از آردوینو") نشان می‌دهد کتابخانه از کدگذاری UCS2 برای متن‌های غیرلاتین پشتیبانی می‌کند (حالت متنی SMS با UCS2).
  • modem.ready() نقطه‌ی اطمینان برای ارسال است؛ پیش از آن ارسال انجام نمی‌شود.
  • الگوی static bool sent یک ارسال یک‌بارمصرف (one-shot) می‌سازد؛ برای ارسال مکرر باید منطق صف (queue) استفاده شود.
  • log::Registry::set_color(false) برای مانیتورهای سریالی که ANSI پشتیبانی نمی‌کنند مفید است.
  • این نمونه از کنترل تغذیه (PWRKEY) استفاده نمی‌کند؛ Modem با آخرین آرگومان پیش‌فرض ساخته شده است.
  • kSim800 برخلاف مثال STM32 که kQuectelM08R است؛ هر دو از یک API بهره می‌برند.

ارتباط با سایر فایل‌ها

  • gsm/ports/arduino/gsm_port_arduino.hpp — ArduinoUart/ArduinoClock که این اسکچ استفاده می‌کند.
  • gsm/modem/modem.hpp — کلاس Modem، SmsService::Received و SmsMessage.
  • gsm/log/log.hpp — log::Registry::set_color.
  • gsm/library.json — پلتفرم‌های atmelavr/arduino را پوشش می‌دهد.
  • در برابر gsm/examples/stm32_main.cpp (نمونه‌ی STM32) قرار می‌گیرد؛ هر دو همان API را نشان می‌دهند.
