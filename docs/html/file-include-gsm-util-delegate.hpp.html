gsm/include/gsm/util/delegate.hpp

نقش فایل

جایگزین سبک‌وزن و بدون heap برای std::function: یک «delegate» قالب‌بندی‌شده با امضای دلخواه که از یک تابع + اشاره‌گر context تشکیل شده است. همهٔ callbackهای کتابخانه (رویدادهای SMS/تماس/Job/URC/سلامت) از این نوع‌اند تا بدون RTTI، استثنا یا تخصیص حافظهٔ پویا کار کنند.

ساختارهای کلیدی

template <typename... Args> class Delegate

template <typename... Args> class Delegate
{
  public:
    using Fn = void (*)(void* ctx, Args...);

    constexpr Delegate() = default;
    constexpr Delegate(Fn fn, void* ctx) : fn_(fn), ctx_(ctx) {}

    void operator()(Args... args) const;   // invoke (no-op if empty)
    explicit operator bool() const;        // bound?
    void     clear();                      // unbind

    template <typename T, void (T::*M)(Args...)> static Delegate bind(T* obj);

  private:
    Fn    fn_  = nullptr;
    void* ctx_ = nullptr;
};
  • سازندهٔ صریح: Delegate(fn, ctx) — تابع ایستا با context دلخواه.
  • operator(): فراخوانی؛ اگر bind نشده باشد بی‌صدا کاری نمی‌کند (فراخوانی امن روی delegate خالی).
  • operator bool: بررسی bind بودن.
  • bind<T, &T::method>(obj): اتصال متد عضو یک object بدون lambda یا heap؛ از یک lambda بدون capture (تبدیل‌شونده به اشاره‌گر تابع) استفاده می‌کند که ctx را به T* cast می‌کند.

نمونه:

// Free function + context (used by Modem's URC trampoline).
Delegate<const UrcEvent&> h{&Modem::urc_trampoline, this};

// Member function binding without std::function.
auto cb = Delegate<const Job&>::bind<App, &App::on_job_done>(&app);

جریان کاری

producer (AtEngine / Modem / services)
    |
    |  delegate(args...)  ==  fn_(ctx_, args...)
    v
consumer method on the bound object   (or plain function)

الگوی trampoline در Modem:

// Static thunk forwards to the instance method via the stored context.
static void urc_trampoline(void* ctx, const UrcEvent& ev)
{ static_cast<Modem*>(ctx)->handle_urc(ev); }

نکات فنی

  • بدون heap، بدون STL، بدون closure: فقط یک اشاره‌گر تابع + یک void*؛ اندازهٔ object ثابت و کوچک (معمولاً ۸/۱۶ بایت).
  • constexpr بودن سازنده‌ها اجازه می‌دهد delegateها در مقداردهی اولیهٔ سراسری ساخته شوند.
  • ایمنی نوعی bind<T, &T::M> در زمان کامپایل بررسی می‌شود (قالب عضو با امضای دقیق)؛ خبری از dynamic_cast نیست.
  • delegate خالی ایمن است: operator() بدون fn_ هیچ کاری نمی‌کند — نیازی به بررسی قبل از فراخوانی نیست (هرچند operator bool موجود است).
  • محدودیت: فقط اشاره‌گر ساده به object؛ هوشمندی مالکیت (shared_ptr و …) ندارد — طول عمر object بر عهدهٔ کاربر است.
  • الگوی استاندارد کتابخانه: using X = Delegate<Args...>; مثل JobCallback، UrcRouter::Handler، SmsService::Received، MaintenanceWatchdog::ReportCb.
