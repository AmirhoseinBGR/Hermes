gsm/tests/host_smoke.cpp

نقش فایل

تست دود (smoke test) میزبان برای کتابخانه ی GSM. این تست بدون سخت افزار واقعی و با استفاده از پُرت میزبان (HostUart/HostClock/HostPowerControl) تمام رفتارهای بحرانی هسته را به صورت قطعی (deterministic) راستی آزمایی می کند: کدک های UCS2، تشخیص اپراتور، ترتیب بوت، کد USSD تعادل، نگهبان سخت گیرانه ی طول پیامک، نظارت تماس با قطع خودکار، تشخیص URC پایان تماس از دست رفته، دروازه ی صف در برابر تماس، بودجه های دوگانه ی بازنشانی نگهداری، پروب های سلامت، بازیابی SIM، پاک سازی صف و واچ داگ سخت افزاری.

ساختارها/توابع کلیدی

نمونه های سراسری:

  • static port::HostUart<2048> uart — UART شبیه سازی شده (تزریق/بازرسی).
  • static port::HostClock clock_ — زمان سنج مصنوعی (now).
  • static port::HostPowerControl pwr — شمارنده ی پالس تغذیه.
  • static Modem modem(uart, clock_, kSim800, &pwr) — مودم SIM800 زیر تست.

توابع کمکی:

  • static void advance(uint32_t ms, uint8_t rounds = 4)

زمان clock_.now را ms جلو می برد و modem.tick() را rounds بار صدا می زند (پیشرفت زمان کنترل شده).

  • static bool tx_has(const char* needle)

بررسی می کند آیا needle در بافر ارسالی (uart.tx()) وجود دارد (یعنی مودم چنین دستوری صادر کرده).

  • int main()

تمام سناریوها را به ترتیب اجرا و با assert راستی آزمایی می کند.

جریان کاری

تست ها در main به ترتیب:

  1. کدک ها و تشخیص اپراتور: codec::utf8_to_ucs2_hex("سلام") → "0633064406270645"؛ detect_operator برای Irancell/MCI/RighTel؛ کدهای پیش فرض تعادل USSD (1411#, 14011#, *140#).
  2. ترتیب بوت: modem.begin() → پاسخ AT → OK → WaitingRegistration → تزریق +CREG: 0,1 → پاسخ به فرمان های بوت استرپ تا modem.ready().
  3. پرس وجوی USSD: modem.check_balance() → AT+CUSD= → تزریق +CUSD → اتمام شغل (JobKind::None).
  4. نگهبان سخت گیرانه ی طول پیامک: متن خیلی بلند → kErrSmsTooLong و kInvalidJob بدون AT+CMGS؛ محدودیت با set_max_chars قابل تنظیم؛ متن کوتاه قبول می شود.
  5. نظارت تماس (قطع خودکار پس از ۲۰ ثانیه): modem.dial → ATD...; → CallState::Outgoing → حلقه ی زمان → AT+CHUP/ATH → CallState::Idle با CallEndReason::Timeout.
  6. تشخیص URC پایان تماس از دست رفته + دروازه ی صف: تماس دوم → پیامک در حین تماس نگه داشته می شود (بدون AT+CMGS) → لیست +CLCC خالی (مثل M08R که NO CARRIER نمی فرستد) → پایان تماس با CallEndReason::NoAnswer → صف دوباره حرکت می کند.
  7. بازنشانی های دوگانه ی نگهداری (بودجه): MaintenanceWatchdog با periodic_ms=1000 و ops_period=3 → بودجه ی زمانی (ResetReason::Periodic) → بودجه ی عملیات (ResetReason::OpsBudget) → درخواست دستی (ResetReason::Manual).
  8. بررسی سلامت پس از بازنشانی: maintenance().start_check() → پاسخ به AT+CSQ/AT+CPIN?/AT+CREG? → health().at_ok و rssi_dbm == -113 + 2*20.
  9. حذف SIM: تزریق +CPIN: NOT INSERTED → ModemState::SimMissing + رویداد SimState::Removed.
  10. بازیابی SIM با چرخه ی CFUN: مشاهده ی AT+CFUN=0 و AT+CFUN=1 → تزریق +CPIN: READY → ModemState::WaitingRegistration.
  11. واچ داگ و پاک سازی صف: pause_queue → شغل SMS → جلو بردن ۴۶ ثانیه (بیش از GSM_JOB_MAX_AGE_MS=45000) → صف خالی (queue_size()==0).
  12. واچ داگ تایم اوت های متوالی: سه بار ارسال ناموفق → افزایش pwr.pulse_count (پاورسایکل سخت افزاری).
  13. پولس غیرمسدودکننده ی PWRKEY + boot guard: power_cycle() بلافاصله برمی گردد (پین را خودش دست نمی زند)، tick() پین را پایین می کشد، ۱۲۰۰ms نگه می دارد، رها می کند و تا پایان GSM_MODEM_BOOT_GUARD_MS هیچ AT نمی فرستد؛ سپس مودم تا Ready بالا می آید.
  14. پاسخ دادن مجدد به ماژول خاموش شده: با سکوت ماژول، کتابخانه خودش پولس بعدی را می زند (off → on) و پس از پاسخ OK وضعیت به WaitingRegistration می رود؛ پین PWRKEY هیچ وقت asserted باقی نمی ماند.

در پایان "ALL TESTS PASSED!" چاپ می شود.

نکات فنی

  • تست ها قطعی هستند؛ زمان با advance و پاسخ ها با uart.inject کنترل می شوند (بدون خواب واقعی).
  • برای ترافیک AT قطعی، housekeeping().enabled=false و maintenance().policy().health_check=false در بخش های مربوطه ست می شوند.
  • نگهبان طول پیامک: kErrSmsTooLong باید در JobCallback گزارش شود و هیچ AT+CMGS ارسال نشود؛ محدودیت با modem.sms().set_max_chars در زمان اجرا تغییر می کند.
  • نظارت تماس: قطع خودکار پس از ~۲۰ ثانیه؛ حالت +CLCC: 1,0,3,0,0 (زنگ/هشدار) نگه داشته می شود تا سرانجام ATH/AT+CHUP.
  • دروازه ی صف: در حین تماس، شغل های SMS ارسال نمی شوند و پس از پایان تماس دوباره فعال می شوند.
  • URC پایان تماس از دست رفته: مودم هایی مثل M08R NO CARRIER/BUSY نمی فرستند؛ لیست خالی +CLCC باید پایان تماس را آشکار کند.
  • بازنشانی نگهداری: هم بودجه ی زمانی (periodic_ms) و هم بودجه ی عملیات (ops_period) باید مستقل کار کنند.
  • سلامت: rssi_dbm از +CSQ: 20,0 با فرمول -113 + 2*rssi محاسبه می شود.
  • بازیابی SIM: چرخه ی AT+CFUN=0/1 (بر مبنای فرمان های مشاهده شده، نه زمان) و سپس +CPIN: READY.
  • پاک سازی صف: شغل های کهنه تر از GSM_JOB_MAX_AGE_MS (۴۵۰۰۰ms) توسط واچ داگ حذف می شوند.
  • واچ داگ سخت افزاری: تایم اوت های متوالی ارسال → پاورسایکل (افزایش pulse_count).
